# Решения

Формат: дата — решение. Почему. Альтернативы.

## 2026-09-23 — Инициализация проекта
Решение: каркас по `/init-project` (Next.js fullstack), урезанный под хакатон: без Serena, team mail,
deployer, CI и цепочки `/dev.*`. Почему: 5 часов, двое, один репозиторий. Альтернативы: полный эталон
(отвергнуто — настройка съест час), без каркаса (отвергнуто — контекст теряется между сессиями и людьми).

## 2026-09-23 — Один Next.js без отдельного бэкенда
Почему: двое фулстеков, 25 баллов за воспроизводимость, стриминг из коробки. Альтернативы: NestJS + Next
(отвергнуто — два README и два процесса), FastAPI + Next (отвергнуто — два языка).

## 2026-09-23 — Без ML (CatBoost) и без Laya в рантайме
Почему: формула Score задана явно, оптимум находится полным перебором за секунды; ML приближал бы
известное. Laya — Python-сервис с точностью 0.36 на typed-decisions без дообучения. Обе идеи в README
как потенциал развития. Альтернативы: суррогатная модель Score (отвергнуто — жюри раскусит).

## 2026-09-23 — Код считает, LLM говорит; факты с ID
Почему: критерии жюри 3 и 5 (детерминированное влияние решений), доверие на демо. Ревизор C1 сверяет
числа в тексте с фактами кодом. Альтернативы: LLM оценивает сценарий сам (отвергнуто — невоспроизводимо).

## 2026-09-23 — Ревизоры: таблица условий, порог 5 из 6, cap 2 круга
Почему: «уверенность» LLM не имеет источника; условия можно включать, выключать и мерить. Cap — чтобы демо
не висело. Альтернативы: score 0–100 от судьи с порогом 80 (отвергнуто), цикл до сходимости (отвергнуто).

## 2026-09-23 — Исход резолюции выбирает код, LLM-арбитр объясняет и разбирает споры
Почему: три исхода (утвердить / с условиями / вернуть) должны быть воспроизводимы и объяснимы формулой.
Альтернативы: арбитр-LLM решает сам (отвергнуто — нельзя ответить «почему утвердил с провалом в Нуре»).

## 2026-09-23 — Без авторизации и без ЭЦП (NCA Node)
Почему: брифом не требуется, NCALayer на машине жюри ломает воспроизводимость. В README строкой про
внедрение в акимате. Альтернативы: муляж кнопки ЭЦП (отвергнуто — заметно и вредно).

## 2026-09-23 — three.js только для 3D-Байтерека на главной
По просьбе Мираса; грузится лениво (next/dynamic, ssr: false) только на `/`, остальные страницы не тянут бандл.
Согласовано с Амиром. Альтернатива: статичная SVG (отвергнуто — нужен интерактивный объект, который можно повернуть).
