# Конвенции

База для фронта: `~/.claude/docs/frontend/frontend-patterns.md` (у Амира). Здесь — только проектное.

- Пакетный менеджер `yarn`. `npm`/`pnpm` не трогать, lock-файл один.
- `src/lib/engine/*` и `src/lib/data/*` — чистые функции и константы, без `fetch`, без `process.env`,
  без импортов из `consilium` или `db`. Причина: движок исполняется и в браузере, и на сервере.
- `src/lib/consilium/*` — только на сервере (`import 'server-only'`).
- Все LLM-вызовы через `consilium/llm.ts`, никаких прямых вызовов SDK из других файлов.
  Причина: retry, трейс токенов и режим без ключа в одном месте.
- Каждый промпт — константа с версией (`EXPERT_PROMPT_V1`), версия пишется в трейс вызова.
- JSON-схемы LLM: поле с обоснованием (`reason`) раньше поля с вердиктом (`passed`, `stance`).
- Компоненты: `src/components/<экран>/<Component>.tsx`, PascalCase, один компонент на файл,
  `'use client'` только там, где есть состояние или события.
- Данные из датасета в коде хранятся как в документе (0–100, стоимость целым числом), округление
  только в форматтерах при показе.
- Идентификаторы: `MeasureId` `M1..M14`, `DistrictId` латиницей (`esil`, `almaty`, `saryarka`,
  `baikonur`, `nura`), русские названия только в словаре для UI.
- Файлы до 300 строк, функции до 50. Разрослось — делить, не оправдывать.
- Тексты для игрока и жюри на русском. Комментарии в коде на английском.
